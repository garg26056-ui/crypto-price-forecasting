# Crypto Price Forecasting

An interactive **cryptocurrency price prediction and market analysis application** built with Python and Streamlit. The application retrieves real-time cryptocurrency market data from the CoinGecko API, visualizes recent price movements, and generates a short-term next-hour price estimate using a linear trend model.

## 🚀 Features

* 📈 Real-time cryptocurrency price retrieval
* 🔍 Search cryptocurrencies by:

  * Name
  * Symbol
  * CoinGecko ID
* 💰 Displays the current cryptocurrency price in USD
* 📊 Fetches the latest **48 hours of hourly market data**
* 🔮 Generates a short-term **next-hour price estimate**
* 📉 Historical price data visualization
* ⚡ Interactive Streamlit dashboard
* 🧾 Displays raw market data for transparency
* 🛡️ Handles API and insufficient-data errors

## 🧠 How It Works

The application follows this workflow:

```text
User selects cryptocurrency
          ↓
Search CoinGecko coin database
          ↓
Fetch current market price
          ↓
Fetch 48 hours of hourly price data
          ↓
Build historical price DataFrame
          ↓
Apply linear trend model
          ↓
Estimate next-hour price
          ↓
Display results in Streamlit
```

## 🤖 Prediction Method

The application uses a simple **linear trend model** based on historical prices.

The model:

1. Takes the available historical price observations.
2. Assigns a sequential index to each observation.
3. Fits a straight line to the historical prices.
4. Uses the fitted trend to estimate the next price point.

The prediction requires at least three historical price observations.

> **Note:** This is a short-term statistical estimate and should not be treated as financial advice.

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/crypto-price-forecasting.git
cd crypto-price-forecasting
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
streamlit run app.py
```

The application will open in your browser.

## 📊 Data Source

Market data is retrieved from the **CoinGecko API**.

The application requests:

* Cryptocurrency listings
* Current cryptocurrency prices
* Historical market prices

The historical data request uses hourly data over a two-day period.

## ⚠️ Limitations

This project is intended for **educational and experimental purposes**.

The prediction model:

* Uses a simple linear trend
* Considers recent historical prices
* Does not account for news or market sentiment
* Does not incorporate trading volume, order-book data, or on-chain metrics
* Cannot reliably capture sudden cryptocurrency market movements
* Should not be considered financial advice
